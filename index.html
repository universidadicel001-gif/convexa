Instalar o desinstalar Convexa

La misma aplicación funciona como PWA en Android y Mac; en Windows también puedes usar el ejecutable incluido en la descarga.

Para instalar en Android o Mac, abre esta página segura (HTTPS) en el navegador del dispositivo.

AndroidChrome → menú ⋮ → “Instalar aplicación” o “Añadir a pantalla de inicio”. Para quitarla: mantén pulsado el icono y elige “Desinstalar”; también puedes hacerlo en Ajustes → Aplicaciones.
WindowsEn el ZIP, ejecuta windows\install-windows.ps1 para instalar Convexa en el menú Inicio; usa “Desinstalar Convexa” para quitarla. También puedes abrir windows\Convexa.exe directamente. Para instalar la versión web, usa Edge o Chrome; desinstálala desde la configuración del navegador. Consulta el README incluido.
MacSafari → Archivo → “Añadir al Dock” (macOS Sonoma o posterior); en Chrome, usa “Instalar página como aplicación”. Para quitarla, arrastra Convexa fuera del Dock y elimínala desde Aplicaciones o Chrome → Aplicaciones.

La opción de desinstalación la controla el sistema o el navegador; Convexa no puede borrar por sí sola una aplicación instalada. Antes de desinstalar, exporta un respaldo de tus imágenes y palabras.
